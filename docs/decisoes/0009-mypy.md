# ADR 0009 — mypy como verificador de tipos

Status: aceita (2026-10-22)

## Decisão
Usar **mypy** em modo `strict` no pacote `pulseops`, com o plugin do Pydantic.

## Motivos
- Instala como dependência Python comum (`uv add --dev mypy`), sem Node.js.
- Tem plugin oficial do Pydantic e suporte do SQLAlchemy 2.x via `Mapped[...]`.
- Healthchecks, um dos projetos de referência, também usa mypy.

## Alternativa
- pyright: mais rápido e com boa inferência, mas depende de Node.js ou de um
  wrapper que baixa o binário.

## Consequências
- Testes são verificados com regras mais leves (`disallow_untyped_defs = false`)
  para não poluir fixtures com anotações sem valor.
